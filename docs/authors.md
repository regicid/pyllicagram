# Authors

## rallicagram

The R package of which the main functions of this package are a port, and from which most of this documentation is adapted:

- [Vincent Bagilet](https://vincentbagilet.github.io/), author and maintainer of [`rallicagram`](https://github.com/vincentbagilet/rallicagram).

## pyllicagram

- [Benoît de Courson](https://regicid.github.io/), author of the functions of pyllicagram 1.x, maintainer.

Vincent Bagilet is credited as the author of the original work. Please report problems with this port on the [`pyllicagram` repository](https://github.com/regicid/pyllicagram/issues).

Gallicagram is developed by Benoît de Courson and Benjamin Azoulay. See the [preprint](https://osf.io/preprints/socarxiv/84bf3/) and the [website](https://www.gallicagram.com/).
